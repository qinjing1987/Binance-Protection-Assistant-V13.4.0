# 币安合约保护助手 V13.3.2「最终轻量回踩版」

V13.3.2 是当前最终稳定基线。自动规则交易采用轻量三指标策略：**5m SuperTrend 主方向、1m RSI 回调触发 + 深度门槛、1m 成交量确认**。自动交易路径不再使用 Bollinger 或 MACD。

## 一、自动交易逻辑

```text
Binance USDⓈ-M 24H 涨跌幅 Top10
        ↓
涨幅 → 只找 LONG / 跌幅 → 只找 SHORT
        ↓
5m SuperTrend（ATR10 × 3）
        ↓
主方向硬过滤 + 1根5m翻转冷静期
        ↓
轻量震荡状态过滤
（6根5m：ST翻转次数 + 波动/ATR + 趋势效率）
        ↓
1m RSI(14) · 触发40/60 · 深度35/65 · 深度回看6根
LONG：从 40 下方重新上穿 40
SHORT：从 60 上方重新跌破 60
        ↓
1m 成交量确认
默认 ≥ 20根均量 × 0.9
        ↓
最近4根结构 + RSI触发K线 + 38.2%回撤
计算被动 LIMIT 入场价格
        ↓
实时 Mark Price / tickSize / ATR 距离检查
        ↓
RiskManager：账户风险 0.5% 默认预算
        ↓
Binance 最小数量 / 最小名义 / 最大杠杆 / 持仓 / 挂单复核
        ↓
GTC LIMIT
```

不会追市价开仓，也不会为了强行出单突破风险预算或 Binance 交易所限制。

## 二、入场点

V13.3 不再机械把 LIMIT 放在单一价格线上，而是综合：

- 最近结构低点/高点；
- RSI 触发 K 线的价格位置；
- 结构极值到触发 K 线收盘价的 38.2% 回撤位置。

三个参考值取中值，再按 LONG/SHORT 方向做被动价格取整，并限制在 Mark Price 的合理距离以内。

默认：

```text
结构回看：4根1m K
结构偏移：0.15 ATR
回撤比例：38%
最大入场距离：1.5 ATR
挂单有效期：5分钟
```

## 三、震荡过滤

不增加 ADX。系统直接使用已有 5m SuperTrend 和 ATR 数据：

- 最近 6 根 5m 的 SuperTrend 翻转次数；
- 最近 6 根价格波动相对 ATR 的大小；
- 趋势效率（净位移 / 总波动区间）。

检测到明显震荡状态时，返回 `5M_MARKET_CHOP`，暂停新的规则开仓。

## 四、出场与保护

### 硬保护

- Binance 固定 SL/TP 为硬保护；
- SL 优先提交和确认；
- TP 进入 Binance Algo 异步队列；
- Algo 限频期间，本地 Mark Price 继续进行保护性兜底；
- 固定 SL/TP 不因指标退出而取消。

### 指标失效退出

浮盈仓位：RSI 或 5m SuperTrend 反向可以主动退出。

浮亏仓位：必须同时满足：

```text
1m RSI 反向
+
5m SuperTrend 反向
+
连续确认 2 根新的 1m 已收盘 K
```

才执行主动退出；否则继续由 Binance 硬 SL 管理。

## 五、真实交易统计

按 UTC 日持久化：

```text
扫描次数
候选数量
有效信号
LIMIT挂出
部分成交
完全成交
TTL撤单
取消/过期
下单失败
挂单成交率
信号→成交率
平均成交等待时间
拒绝原因
```

页面规则交易面板直接显示：

```text
今日信号 / 挂出 / 成交 / TTL撤单 / 成交率 / 平均等待
```

这样可以区分：

```text
信号太少
入场条件太严
LIMIT距离太远
Binance最小订单限制
挂单没有成交
```

而不是只显示一个 `eligible: 0`。

## 六、风险与默认值

```text
单笔账户风险：0.5%
最大实持仓：1
最大待成交 LIMIT：2
同币冷却：10分钟
规则杠杆：10x（仍需通过 Binance 每个合约最大杠杆复核）
结构SL：0.4%～2.5%
默认TP：2R
日亏损上限：0 = 关闭百分比熔断
```

即使日亏损百分比熔断关闭，账户权益读取失败、最小订单不满足、最大持仓、最大杠杆等硬条件仍不会被绕过。

## 七、UI

当前页面集中展示：

- 实时持仓与 Binance 实际 SL/TP；
- 5m SuperTrend 主方向；
- 1m RSI 状态；
- 1m 成交量倍数；
- 规则扫描状态；
- 最近规则信号；
- 真实交易统计；
- 浮亏失效退出状态；
- 系统诊断和事件日志。

## 八、VS Code 运行

```powershell
npm install
npm run check
npm test
npm start
```

启动后访问：

`http://localhost:3000`

首次启动建议保持规则自动交易关闭，确认 Binance API、WS、时间同步、保护和统计均正常后再开启主网自动交易。

## 九、重要说明

V13.3.2 是当前策略稳定基线，不代表已经证明胜率高于其他参数或其他策略。实际策略质量应以同一批历史数据的回测、模拟盘以及真实的“信号→挂单→成交→平仓”统计为依据。
