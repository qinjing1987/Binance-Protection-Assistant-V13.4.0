# 币安合约保护助手 V11.0 开发运行说明

## 1. 环境

建议 Node.js 20+。你之前的 Node.js 24.x 也可以作为 npm/electron 的开发环境使用。

## 2. VSCode

用 VSCode 打开项目根目录：

`Binance-Protection-Assistant-V11.0`

终端运行：

```powershell
npm install
npm run check
npm test
npm start
```

以后直接运行：

```powershell
npm start
```

也可以双击 `run-dev.bat`。

## 3. 第一次启动

如果还没有 Binance API，界面会显示“未连接”，这是正常的。

打开“设置中心”：

1. 输入 Binance API Key / Secret。
2. 选择实际账户持仓模式；不要让软件自动切换你的账户模式。
3. 点击“测试币安连接”。
4. AI 实盘保持关闭。
5. 自动保护默认开启。

## 4. API 安全

API 必须关闭提现权限；最好设置 IP 白名单。API Secret 不写入 `.env`，Windows 版由 Electron safeStorage 加密保存。

## 5. 第一次实盘测试

先用很小的真实仓位验证：

手机 Binance 开一笔测试仓位 → 电脑程序发现 → 查看 SL/TP 是否出现在 Binance 条件单里 → 再手动平仓 → 程序确认仓位归零。

不要第一次就开启 AI 自动交易。
