# 接口与安全说明

## Binance

本项目只面向 Binance USDⓈ-M USDT 永续。

当前条件单使用 `/fapi/v1/algoOrder`，查询使用 `/fapi/v1/openAlgoOrders`，普通 MARKET 开仓/平仓仍使用 `/fapi/v1/order`。

所有符号在业务层统一为 Binance 原生 `BTCUSDT` 形式。

## 用户数据流

使用 listenKey 私有流：

`wss://fstream.binance.com/ws/<listenKey>`

程序同时保留 REST 轮询作为安全兜底。

## 保护规则

- LONG 固定保护：SELL STOP_MARKET + SELL TAKE_PROFIT_MARKET
- SHORT 固定保护：BUY STOP_MARKET + BUY TAKE_PROFIT_MARKET
- 固定保护使用 `closePosition=true`，不发送 quantity/reduceOnly。
- Hedge Mode 下严格使用 LONG/SHORT positionSide。
- Trailing 在 `ia=true` 激活前不撤固定 SL。
