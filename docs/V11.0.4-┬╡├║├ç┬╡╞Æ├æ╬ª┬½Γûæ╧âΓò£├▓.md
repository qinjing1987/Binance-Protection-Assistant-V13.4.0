## 本版重点修复

1. Binance REST 签名参数统一构造，参数按 key 排序并进行 RFC3986 percent-encoding。
2. `BinanceClient.rawRequest()` 禁止 path 携带 `?query`，从代码层阻止查询参数重复拼接。
3. 服务器时间偏移集中管理，正常 3 分钟刷新一次，遇到 `-1021` 自动重新同步并只重试一次。
4. `LeverageBracket` 的 symbol 改为 params 传递。
5. User Data Stream 23 小时换代 timer 独立管理，避免旧 timer 影响新连接。
6. Logger 脱敏规则重新整理。
7. 前端改为更完整的量化终端布局，并增加设置中心、诊断、风险、保护健康度、行情、日志等信息。
8. DeepSeek 设置预置为 `https://api.deepseek.com` + `deepseek-v4-pro`，AI 实盘仍默认关闭。

## Binance 实盘测试限制

当前环境无法直接使用用户的真实 API Secret 进行交易所实盘操作测试，因此本版只完成本地代码、结构、语法和单元测试。第一次真实使用前，仍应先用小额/低风险环境验证：

`手机开仓 → 程序发现 → Binance Algo SL/TP 创建 → Binance 复核 → 关闭仓位 → 保护清理`。
